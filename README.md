# CSET-220-Soft-Project
Smart-HR Company Management Program.
1. This project is a simple yet effective company management tool that allows admins and employees to operate the business' employee schedules, hours and salary with ease.
2. This program has functions that allows admins to log in, view the statistics of their company's statistics, their employees' statistics and approve/deny requests of leave. Employees can log in, check in and out of work and view their statistics. This project used Laravel and Bootstrap, and primarily was inspired by DKG. Many of the images came from Pexels.
